# FIDO2 Security Keys on Amazon US: Listing and Review Snapshot

Public data behind a retrospective check of a security-key launch.

- `market.csv`: top 20 organic and sponsored results for "fido2 security key" on amazon.com, viewed Nov 19, 2026: price, rating, review count, "bought in past month" badge (lower bound), connector, NFC and biometric flags.
- `reviews_coded.csv`: the 10 most recent critical (1–3 star) reviews for six keys, each coded by hand with a primary complaint (setup, defect, expectation gap, compatibility, fit, NFC, service, other) and a one-line summary. Review text itself is not redistributed.

Limits: a single-day snapshot; badges are floors, not exact sales; ten reviews per product supports direction, not precise shares.
